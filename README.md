# 🚀 Bhushan - Developer Portfolio

A modern, responsive personal portfolio website showcasing my skills, projects, and journey as a developer. Built entirely from scratch with a focus on clean design, smooth animations, and a fully functional contact system.

🔗 **Live Demo:** [your-live-link-here]

## ✨ Features

- 🎨 Modern dark theme with glassmorphism UI elements
- ⌨️ Dynamic typing animation powered by Typed.js
- 📱 Fully responsive design (desktop, tablet, mobile)
- 🛠️ Categorized skills section (Programming, Web Dev, Database, Tools)
- 📂 Project showcase with live GitHub links
- 🎓 Interactive education timeline
- 📩 Functional contact form (Formspree) with AJAX submission and in-page success message — no page redirect
- 📄 One-click resume download
- 🔗 Quick links to GitHub, LinkedIn, and email

## 🧰 Tech Stack

- **HTML5** – Semantic structure
- **CSS3** – Custom styling, Flexbox, Grid, responsive media queries
- **JavaScript** – Form handling, DOM interaction
- **[Typed.js](https://github.com/mattboldt/typed.js/)** – Typing animation
- **[Font Awesome](https://fontawesome.com/)** – Icons
- **[Formspree](https://formspree.io/)** – Contact form backend
